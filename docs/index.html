Rutas de múltiples puntos, sin servidor de ruteo

Librería ligera para generar rutas por calles reales en una zona específica, sin conexión y sin instalar OSRM ni un motor de ruteo grande. Calcula la ruta más corta en distancia entre las paradas, con instrucciones en español y, si se pide, un mejor orden de visita.

Probar Visualizador Web Explorar Documentación Repositorio GitHub

Qué hace

  • Ruta más corta en distancia entre paradas consecutivas
  • Distancia total, polilínea e instrucciones por calle
  • Mejor orden de visita (opcional): exacto hasta 9 paradas
  • Sin internet, en la zona que elijas (grafo generado desde OpenStreetMap)

Qué no hace todavía

  • Tiempos de llegada, velocidades y tráfico (posible mejora)
  • Restricciones de giro; el grafo de ejemplo ignora los sentidos de las calles
  • Navegación en tiempo real
  • Grafos muy grandes (un estado o un país completo)

Ejemplos rápidos de integración

Usa el motor de rutas desde TypeScript, Electron o directamente desde la terminal

Ver documentación de la API 
import { calcularRuta, RespuestaRutaCompleta } from 'ruta-craft-osm';

// Cálculo de ruta multi-parada con el motor C++ nativo
const respuesta: RespuestaRutaCompleta = await calcularRuta({
  puntos: [
    [29.065639, -110.056448], // Origen (A)
    [29.062039, -110.059091], // Parada 1
    [29.059486, -110.053973], // Parada 2
    [29.118091, -109.970340]  // Destino (B)
  ]
});

console.log(`Distancia: ${respuesta.resultado.distancia_total_km} km`);
console.log(`Puntos polilínea: ${respuesta.resultado.ruta.length}`);
console.log(respuesta.resultado.instrucciones[0]); // { accion: "Sigue recto", calle: "...", distancia_m: ... }
const { app, ipcMain } = require('electron');
const path = require('path');
const { crearMotorRutas } = require('ruta-craft-osm');

// Proceso main: un solo motor con el grafo cargado en memoria (< 1 ms por ruta)
const motor = crearMotorRutas({
  cachePath: path.join(app.getPath('userData'), 'cache_rutas.json')
});

ipcMain.handle('calcular-ruta', (_evento, puntos) => motor.calcular(puntos));

// Ordenar las paradas para recorrer lo menos posible y volver al inicio
ipcMain.handle('ruta-optimizada', (_evento, puntos) =>
  motor.calcular(puntos, { optimizar: true, regresarAlInicio: true }));

// Guardar el caché al salir
app.on('before-quit', () => motor.cerrar());
# Desde ruta-craft-osm/bin/win32-x64/ (el motor encuentra el grafo en ../grafos/)
.\cli.exe --array 29.065639 -110.056448 29.059486 -110.053973 --sin-cache

# Puntos desde un archivo JSON y resultado en otro archivo
.\cli.exe --puntos paradas.json --salida ruta.json
